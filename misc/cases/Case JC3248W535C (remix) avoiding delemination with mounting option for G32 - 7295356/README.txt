Remixed remix case for the ESP32S3 3.5" touchscreen module JC3248W535C.Original model: https://www.thingiverse.com/thing:7127557Remixed model: https://www.thingiverse.com/thing:7182655 IF your JC3248W535C display tends to lift off the plastic carrier (due to bad adhesion), this model is for you!If not: go with one of the original designs instead. :)The ESP32 dev board module is secured with four M2x4 mm, M2x5 mm, or M2x6 mm threaded screws.There are 3 different designs available:The remix case remixed with minor changes:there is an additional bezel that clips to the ESP32 display and prevents the top display from separatingA hanger that serves as an add-on for the case  (only intended to be used with this case model because it takes the added bezel into consideration).In case you happen to own a G32 Connected gas grill, this repository might be of interest to you: https://github.com/sagdusmir/G32-Grill-Display-480x320-BTprefIMPORTANT:- Do not print with supports!- You might need to drop the bottom of the model onto the print bed in your slicer - Before installing the display, the cover plate on the back of the display must be removed!- Before tightening down the screws, check if the collar around the USB-C port causes any distress to the PCB or its components!  (the display detaches from  its mounting frame if there is any force applied from the back by the case)
