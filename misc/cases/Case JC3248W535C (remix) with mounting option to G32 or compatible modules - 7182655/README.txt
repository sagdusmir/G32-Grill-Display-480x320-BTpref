Remixed case for the ESP32S3 3.5" touchscreen module JC3248W535C.Original model: https://www.thingiverse.com/thing:7127557 If your displays tends to lift itself off the plastic carrier, check this out: https://www.thingiverse.com/thing:7295356 The ESP32 dev board module is secured with four M2x4 mm, M2x5 mm, or M2x6 mm threaded screws.There are 3 different designs available:The original case remixed with minor changes:The clearance for the button was reduced by about 0.3mm (less force required to operate the button).Added collar around the USB-C port to hold down the PCB and prevent flex if the USB-C plug is removed.The remixed case what can be hooked into any G32 Connected handles or the handles of compatible modules (this is an alternative ESP32 case)A hanger that serves as an add-on instead of a replacement for the case  (compatible with the original case or the remixed one).In case you happen to own a G32 Connected gas grill, this repository might be of interest to you: https://github.com/sagdusmir/G32-Grill-Display-480x320-BTprefIMPORTANT:- Do not print with supports!- You might need to drop the bottom of the model onto the print bed in your slicer - Before installing the display, the cover plate on the back of the display must be removed!- Before tightening down the screws, check if the collar around the USB-C port causes any distress to the PCB or its components!  (the display detaches from  its mounting frame if there is any force applied from the back by the case)Updates2026-02-12 The case with the included hanger has been updated for easier printing and offers slightly more space for internal components.
